
# 🧩 Nummazed

> **Permainan puzzle berbasis angka yang menguji logika, ketelitian, dan kemampuan memecahkan masalah.**

## 📖 Tentang Nummazed

**Nummazed** adalah permainan puzzle berbasis angka yang dirancang untuk mengasah kemampuan berpikir logis dan pemecahan masalah pemain.

Dalam permainan ini, pemain dihadapkan pada suatu susunan angka dan perlu menentukan langkah yang tepat untuk mencapai tujuan permainan. Setiap langkah membutuhkan ketelitian dan strategi agar puzzle dapat diselesaikan dengan baik.

Nama **Nummazed** merupakan gabungan dari kata **"Number"** dan **"Maze"**, yang menggambarkan konsep permainan yang menggabungkan angka dengan mekanisme puzzle.

## 🕹️ Cara Bermain

Tujuan utama **Nummazed** adalah menyelesaikan puzzle dengan mengikuti aturan permainan yang tersedia.

1. Jalankan program **Nummazed**.
2. Perhatikan susunan angka pada permainan.
3. Gerakkan karakter menggunakan **WASD** atau **tombol panah**.
4. Tentukan setiap langkah dengan mempertimbangkan posisi dan kondisi puzzle.
5. Lanjutkan hingga tujuan permainan tercapai.
6. Cobalah menemukan strategi yang efektif untuk menyelesaikan puzzle.

### 🎛️ Kontrol

| Tombol | Tombol Alternatif | Fungsi            |
| :----: | :---------------: | ----------------- |
|   `W`  |        `↑`        | Bergerak ke atas  |
|   `A`  |        `←`        | Bergerak ke kiri  |
|   `S`  |        `↓`        | Bergerak ke bawah |
|   `D`  |        `→`        | Bergerak ke kanan |

> **💡 Tips:** Kamu dapat menggunakan **WASD** maupun **tombol panah**, sehingga dapat memilih kontrol yang paling nyaman.

## 🚀 Cara Menjalankan

### 1. Clone Repository

```bash
git clone https://github.com/wobblyorbee/Nummazed-.git
```

### 2. Masuk ke Folder Project

```bash
cd Nummazed-
```

### 3. Compile

Jika menggunakan `g++`:

```bash
g++ main.cpp -o Nummazed
```

### 4. Jalankan

Windows:

```bash
Nummazed.exe
```

Linux/macOS:

```bash
./Nummazed
```
